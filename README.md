# MediaHub-desktop v1.0.0

project WHY(Web Hub Yard) MediaHub-desktop

> MediaHub is encrypted media streaming service for users who want to share data with others

## Usage

- This is desktop client for MediaHub, designed for large file uploading
- Auto-login supported by by OS keyring (Windows Linux MacOS)
- There is no executable file, so run python app directly

## Run Program

```bash
cd code
pip install -r requirements.txt
python app.py
```
